Recon asset manager for bug hunters

rainman

Your recon tools each write their own flat file. rainman merges all of them into one deduplicated graph of the attack surface, then lets you query it, triage it, and pipe results back into your tools.

13tool importers
12node types
11edge types

The graph on this page is a small example target, example.com, built from the same model the app uses. Nothing here is real scan data.

Click a node to expand or collapse its neighbours
Ingest

One line of tool output becomes nodes and edges

Each importer is a pure parser. Everything it emits goes through one write path, so import order does not matter, re-importing never duplicates, and an import either lands completely or not at all.

Triage

      
Every asset carries a status, and only legal moves are allowed

      
Status lives on the node next to your tags, notes and findings. The same rules apply in the UI, in bulk actions and to anything written through the API. Pick a status to see where it can go next.

    

    

      

      

    

  


  

    

      
Inside

      
A small core with adapters around it

      
The core knows nothing about tools, HTTP or the database. That keeps deduplication in one place and makes a new importer a single file.

Verified

      
What has been tested

    

    

      
98 / 98automated tests pass, covering every importer, the query language, ingest guarantees, the CLI and the API.

      
4,900+malformed imports and hostile queries sent at the API. None caused a server error.

      
40+UI checks in a real headless browser across the graph and table views, including a crafted URL that must not run script.

      
1,840 URLs/simport rate on a 20,000 URL archive dump. 100,000 URLs (300,000 nodes) took 65 seconds.

    

    
Also checked: the Docker image builds and serves, a database from the previous version migrates in place, and the packaged wheel includes the UI. Not checked: output captured from live tool runs. The importer samples follow each tool's documented format.

    

      

$ pip install -e .
$ rainman import httpx httpx.jsonl      # prints how many assets are new
$ rainman leads                         # where to look next
$ rainman query 'type:endpoint code:401|403' | your-tool
$ rainman serve                         # graph + table UI on localhost:8000
